# 🌙 MoodMate (대학생 정서 관리 서비스)

> **"오늘 당신의 마음은 어떤 날씨였나요?"**  
> 대학생들의 감정과 스트레스 요인을 기록하고 분석하여 심리적 객관화를 돕는 웹 서비스입니다.

## 1. 프로젝트 개요
대학생들이 겪는 학업, 취업, 인간관계 등 다양한 스트레스 요인을 체계적으로 기록하고, 이를 시각화된 데이터로 제공하여 자기 이해를 높이는 데 목적이 있습니다.

## 2. 주요 기능
- **회원가입/로그인:** 사용자별 데이터 격리 (LocalStorage 기반 모사)
- **감정 기록:** 5가지 감정 아이콘 및 1~5점 척도 강도 기록
- **스트레스 분석:** 8가지 요인별 중요도 동시 기록
- **감정 일기:** 500자 내외의 짧은 일기 작성
- **감정 캘린더:** 월별 감정 흐름을 아이콘으로 한눈에 파악
- **통계 대시보드:** Chart.js를 이용한 감정 빈도 및 스트레스 패턴 시각화
- **개인 리포트:** 최근 30일 데이터 분석을 통한 자동 텍스트 리포트 생성

## 3. 기술 스택
- **Frontend:** HTML5, CSS3 (Flexbox/Grid), JavaScript (ES6+)
- **Visualization:** [Chart.js](https://www.chartjs.org/)
- **Storage:** Browser LocalStorage (DB 대체)

## 4. 실행 방법
1. `MoodMate.html` 파일을 다운로드합니다.
2. 크롬(Chrome)이나 웨일(Whale) 등 웹 브라우저로 파일을 엽니다.
3. 회원가입 후 로그인을 진행하면 모든 기능을 사용할 수 있습니다.
