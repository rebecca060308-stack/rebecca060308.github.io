# 🤝 TeamSync (팀싱크) - 팀 협업 및 스케줄링 플랫폼

> 팀원들의 빈 시간을 시각적으로 확인하고, 회의 시간을 추천받으며, 칸반보드로 업무를 관리하는 협업 웹 서비스입니다.

---

## 🚀 주요 기능 및 문제 분해 (Problem Decomposition)

### ① 회원가입 및 로그인 기능
* **1단계: 회원가입**
  * 이메일, 비밀번호, 닉네임 입력 기능
  * 비밀번호 유효성 검사 (영문+숫자 8자리 이상 등) 적용
* **2단계: 로그인**
  * 이메일/비밀번호 일치 여부 확인
  * 로그인 성공 시 **JWT(JSON Web Token)**를 발행하여 로그인 인증 상태 유지
* **3단계: 팀 생성 및 초대**
  * '새 팀 만들기' 기능 (팀 이름 입력)
  * 팀별 고유 초대 링크 및 코드 생성 기능

### ② 팀원 간 "빈 시간" 시각화 및 회의 시간 추천
* **1단계: 개인 공유 가능 시간 입력**
  * 달력(Calendar) UI 기반 인터페이스
  * 드래그 앤 드롭(Drag & Drop)을 통한 바쁜 시간대 지정
* **2단계: 시간표 겹쳐 보기 (Merge Layer)**
  * 팀원들의 시간표 데이터를 하나의 달력 위에 레이어로 중첩
  * **시각화:** 모두가 비어 있는 시간은 밝은색, 바쁜 인원이 많을수록 어두운색으로 불투명도 조절
* **3단계: 최적의 회의 시간 추천 알고리즘**
  * DB에서 '모든 팀원의 공통 빈 시간' 추출
  * 공통 빈 시간이 긴 순서대로 **Top 3 추천 시간대** 화면 노출

### ③ 칸반보드 기반 업무 분배 및 진척도 관리 (To-Do)
* **1단계: 업무 카드 생성**
  * 업무 내용, 담당자(팀원 선택 드롭다운), 마감일 입력 및 카드 추가
* **2단계: 상태 변경 (Drag & Drop)**
  * 3개 칼럼 구성: `할 일(To-do)` ➔ `진행 중(In Progress)` ➔ `완료(Done)`
  * 마우스 드래그로 카드 이동 시 DB의 `status` 값 실시간 업데이트
* **3단계: 진척도 바(Progress Bar) 표시**
  * 진척도 계산식 적용: $\frac{\text{완료된 카드 개수}}{\text{전체 카드 개수}} \times 100 (\%)$
  * 대시보드 상단에 시각적인 게이지 바(%) 표현

## 🛠 Tech Stack (예정)
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS 또는 React)
* **Backend:** Node.js (Express) 또는 Python (FastAPI / Django)
* **Database:** PostgreSQL 또는 MongoDB
